# CRO V-Lab V3# 

CRO V-Lab — Virtual CRO & Function Generator Laboratory

V3 adds an actual React Three Fiber 3D laboratory scene, interactive 3D knobs, mathematical waveform-style rendering, signal controls, fault injection, AI-guided diagnosis, manual measurement practice, CRT intensity/focus controls, and an X-Y/Lissajous mode toggle.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Note

This is the hackathon MVP foundation. Spectator/multi-user mode and full two-independent-channel Lissajous rendering are intentionally left as stretch goals after the core lab flow is stable.
